AI Agent Readiness Advisor jako skill pro AI agenty

Metodika i znalostní soubory jsou stejné jako u průvodce v projektu v ChatGPT nebo Claudu. Průvodce je tu ale zabalený jako složka se souborem SKILL.md podle standardu Agent Skills. AI agent v terminálu nebo v IDE si ji načte sám, když se ho zeptáte na téma, kterého se týká, třeba jestli pustit agenta k restartům služeb.

Pokud chcete průvodce jen vyzkoušet v chatu, skill nepotřebujete. Stačí hlavní stránka a bezplatný účet.

Pro koho to je

Pro vývojáře, SRE a lidi z provozu, kteří už pracují s Claude Code, Codexem nebo podobným nástrojem v terminálu nebo v IDE. Výhoda je, že posouzení proběhne tam, kde máte konfiguraci agenta. Agentovi ukážete soubor s jeho právy nebo seznamem nástrojů a průvodce úroveň autonomie určí podle toho, co v souboru je.

Skill potřebuje placený plán nebo API přístup. Claude Code ani Codex v terminálu a v IDE v bezplatném plánu nejsou, podrobnosti jsou v instalaci níže.

Když s takovým nástrojem nepracujete, použijte průvodce v ChatGPT, Claudu, Gemini nebo Copilotu podle hlavní stránky. Metodika je stejná.

Instalace do Claude Code

Co potřebujete: Claude Code podle dokumentace Anthropicu vyžaduje účet Pro, Max, Ultra, Team, Enterprise nebo Console. Bezplatný plán Claude ho nezahrnuje. Jde použít i přes Amazon Bedrock, Google Cloud nebo Microsoft Foundry. Ověřeno 3. 11. 2026 na code.claude.com/docs/en/setup.

  1. Stáhněte zip a rozbalte ho. Uvnitř je složka agent-readiness-advisor.
  2. Složku zkopírujte do ~/.claude/skills/. Skill pak máte ve všech projektech na svém počítači. Pokud ho má mít celý tým, dejte složku do .claude/skills/ v repozitáři a commitněte ji.
  3. Ověřte, že ho Claude Code vidí: v session napište /skills a v seznamu má být agent-readiness-advisor.

Na macOS a Linuxu jde krok 1 a 2 udělat jedním příkazem:

mkdir -p ~/.claude/skills
unzip agent-readiness-advisor-skill-cz.zip -d ~/.claude/skills/

Další nástroje

Skill dodržuje otevřený standard Agent Skills (agentskills.io): složka se souborem SKILL.md a podsložkou references. Standard určuje, jak má složka vypadat, ale neříká, kam ji nástroj ukládá. U jiného nástroje najdete umístění v jeho dokumentaci.

Co agent se skillem smí

Agent v Claude Code nebo Codexu umí číst soubory, spouštět příkazy a volat další nástroje. Skill mu pro posouzení dává tato pravidla:

  • Čte jen to, co mu ukážete: text vložený do konverzace nebo soubor, na který odkážete cestou a řeknete, ať ho přečte. Repozitář ani prostředí sám neprochází.
  • Nic nemění a nic nespouští. Neupravuje soubory, nespouští příkazy, nevolá API ani MCP nástroje a nezkouší, jak se váš agent chová.
  • Když se konfigurace, kterou ukážete, liší od vašeho popisu, řekne to a počítá s právy z konfigurace.
  • Tokeny, hesla, klíče a jiné Secrets z ukázaných souborů necituje.
  • Decision record uloží do souboru, jen když o to výslovně požádáte. Cestu a název navrhne a nechá si je potvrdit, existující soubor nepřepíše.

Skill je instrukce pro model. Práva agenta technicky neomezuje, to dělá nastavení oprávnění v Claude Code nebo v Codexu. Průvodce stejně hodnotí i vaše agenty: když meze hlídá jen prompt, dostane samostatně jednající agent 🔴.

Skill prošel 3. 11. 2026 stejným benchmarkem jako průvodce ve variantě projekt. Scénář byl stejný: Event-Driven Ansible v Red Hat AAP, ve kterém jazykový model píše playbooky na nápravu. Proti průvodci stál stejný simulovaný vedoucí provozu a rozhovor na konci hodnotil soudce. Ve všech třech rolích běžel Claude Opus 5.5.

Simulovaný uživatel popsal svou situaci vlastními slovy a skill ani metodiku nezmínil. Agent skill použil sám hned v první odpovědi, v češtině i v angličtině.

AI Agent Readiness Advisor as a skill for AI coding agents

The method and the knowledge files are the same as for the guide in a ChatGPT or Claude project. Here the guide comes as a folder with a SKILL.md file, following the Agent Skills standard. An AI agent in your terminal or IDE loads it by itself when you ask about something it covers, for example whether to let an agent restart services.

If you only want to try the guide in a chat, you don't need the skill. The main page and a free account are enough.

Who it is for

For developers, SREs and operations engineers who already work with Claude Code, Codex or a similar tool in the terminal or an IDE. The advantage is that the assessment happens where your agent's configuration lives. You show the agent the file with its permissions or tool list, and the guide sets the autonomy level from what the file contains.

The skill needs a paid plan or API access. Neither Claude Code nor Codex in the terminal and IDE is part of a free plan; details are in the setup sections below.

If you don't work with such a tool, use the guide in ChatGPT, Claude, Gemini or Copilot as described on the main page. The method is the same.

Other tools

The skill follows the open Agent Skills standard (agentskills.io): a folder with a SKILL.md file and a references subfolder. The standard defines what the folder looks like, but not where a tool keeps it. For other tools, check their documentation for the location.

What the agent may do with the skill

An agent in Claude Code or Codex can read files, run commands and call other tools. For the assessment, the skill gives it these rules:

  • It reads only what you show it: text pasted into the conversation, or a file you point to by path and ask it to read. It does not browse the repository or the environment on its own.
  • It changes nothing and runs nothing. No file edits, no commands, no API or MCP tool calls, no trial runs of your agent.
  • If the configuration you show differs from your description, it says so and goes with the permissions in the configuration.
  • It does not quote tokens, passwords, keys or other secrets from files you show it.
  • It saves the decision record to a file only when you explicitly ask. It proposes the path and name, asks you to confirm them and never overwrites an existing file.

The skill is an instruction to the model. It does not technically restrict the agent's permissions; the permission settings in Claude Code or Codex do that. The guide applies the same rule to your agents: if only the prompt enforces the limits, an agent that acts alone gets 🔴.

How the skill has been tested

On 3 November 2026 the skill went through the same benchmark as the guide in the project setup. The scenario was the same: Event-Driven Ansible in Red Hat AAP, where a language model writes remediation playbooks. The guide faced the same simulated head of operations, and a judge scored the conversation at the end. Claude Opus 5.5 ran in all three roles.

The skill was installed as a project skill in .claude/skills/ in a new empty directory. Claude Code ran with its default system prompt, with no user settings and no MCP servers, and could only read files. The simulated user described the situation in their own words and mentioned neither the skill nor the method. The agent used the skill on its own in its first reply, in both Czech and English.

A run passes when all automated checks pass and the judge gives at least 80 % of the points. Both runs passed. The judge gave the Czech version 86 % and the English version 95 %, and in both languages the guide delivered the assessment after three replies.
